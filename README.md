## Instalar y ejecutar

```bash
git clone https://github.com/USUARIO/Apellido_Nombre_CarritoReact.git
cd Apellido_Nombre_CarritoReact
npm install
npm run dev
```

Abre la URL que muestra la terminal (normalmente http://localhost:5173).
